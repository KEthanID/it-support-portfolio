# A desktop kept shutting down

> **Fictional example:** This shows the writing style, not a participant's completed work.

**Setting:** Supervised hardware simulation

## Problem or goal

A desktop turned on briefly, then shut down before Windows loaded. The user couldn't get to the sign-in screen.

## What I found

The CPU cooling fan's cable was disconnected. The fan wasn't running, which pointed to a cooling problem during startup.

## My approach

I used the power and fan behavior to narrow the problem down. A secure power connection and moving case fans made the stationary CPU fan a useful clue. With my instructor's guidance, I inspected and corrected the fan connection while following power-disconnection and static-safety precautions.

## Result

The fan ran and the computer reached the Windows sign-in screen on two starts. Those checks showed startup was working again; I didn't test long-term performance.

## Skills in practice

CompTIA A+ concepts: hardware troubleshooting, CPU cooling, and safe component handling.
